# 新会话只在同一工作区或 Project 内继承模型

**状态：暂缓，不纳入 v0.17.0。** 来源：[PR #28](https://github.com/frostime/pi-vscode-ui/pull/28)。

在同一工作环境下新开会话时，用户希望继续使用正在用的提供商和模型。#28 从全局激活会话取模型，没有验证它是否属于新会话的目标工作环境。VS Code 从会话标签页发起新建时，目标目录可来自源标签，侧栏激活的会话却可能属于另一个工作区。

建议以新会话的归属为准：Desktop 只从目标 Project 中当前选中的会话继承；VS Code 只从同一 workspace folder 的会话继承，从会话标签页发起时以源标签为准。没有合适来源或继承的模型不可用时，保留 Pi 的启动选择；显式启动配置优先。不增加独立的项目模型偏好，不改变 Resume 或 `/new`。

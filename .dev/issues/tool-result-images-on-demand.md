# 按需查看工具返回的图片

**状态：暂缓，不纳入 v0.17.0。** 来源：[PR #27](https://github.com/frostime/pi-vscode-ui/pull/27)。

工具卡片目前只显示文本，无法直接查看浏览器截图或 `read` 返回的图片。希望实时会话和重新打开的历史都能在对应工具卡片中查看图片。

#27 将每张原图的 Base64 数据放进会话视图。单图限制不能约束整份视图的大小；多张合规图片加起来仍可能超过 Desktop 的 32 MiB 消息上限，导致整份对话无法显示。仅在折叠时卸载组件，无法解决传输发生在渲染之前的问题。

建议折叠时只显示图片入口，不在会话快照或增量里传原图。展开时单独取图；收起时释放界面持有的图片数据。单张图过大或取图失败时，只影响该图片，不影响对话。Pi 仍负责保存会话历史。
